# Flutter Demo Application

## Project Overview

This is a simple demo mobile application developed using Flutter.

The purpose of this project is to demonstrate the basic structure of a Flutter application, including UI design, navigation, and basic functionality.

This app is built for just familier with Flutter and dart. It is not a Grand app.. just a basic and smiple..


## Features

- Simple and clean user interface
- Responsive layout
- Basic navigation between screens
- Demonstrates Stateful and Stateless widgets
- Cross-platform support (Android and iOS)


## Technologies Used

- Flutter
- Dart
- Material Design Components

## How It Works

1. The main.dart file is the entry point of the application.
2. The MaterialApp widget initializes the app.
3. Screens are built using StatelessWidget or StatefulWidget.
4. UI components are designed using Flutter Material widgets.
5. Navigation is handled using Navigator.


## Installation

1. Clone the repository:

```
git clone <repository-link>
cd flutter_demo_app
```

2. Install dependencies:

```
flutter pub get
```

3. Run the application:

```
flutter run
```
